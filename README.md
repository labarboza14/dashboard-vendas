# 📊 Dashboard de Vendas com Streamlit + Google Sheets

Este projeto é um exemplo de dashboard interativo feito com **Streamlit**, conectado a uma **planilha no Google Sheets em tempo real** e exposto com **ngrok** para acesso público. Ideal para fins de **estudo, prática de Python e visualização de dados**.

## ✨ Funcionalidades

- Conecta-se a uma planilha no Google Sheets com dados de vendas
- Exibe métricas estratégicas: faturamento, vendas por canal, formas de pagamento e mais
- Atualiza os dados em tempo real ao modificar a planilha
- Gráficos interativos com Plotly
- Layout bonito, profissional e intuitivo com Streamlit
- Acesso remoto via ngrok

## 📁 Estrutura dos Dados

Os dados são fictícios, simulando uma operação de vendas. A planilha contém as colunas:

- `Data`
- `Produto`
- `Quantidade`
- `Valor`
- `Total`
- `Canal da Venda`
- `Forma de pagamento`
- `Vendedor`
